# Sim Real Witness

Sim Real Witness is being built to compare a declared simulator and actual fabric under the same complete network and logical inputs. It will retain spike matching, rate and observable-state differences, optional measured-energy comparison and the measurement chain's uncertainty. This checkout contains repository validation tooling and documentation. Full foundation qualification is in progress. There is no installed simulation-to-fabric comparison package, paired runner, public comparison command or qualified fidelity certificate.

## Boundary

This project owns the paired experiment, source interpretation, deterministic matching, metrics, statistical treatment and scoped evidence. SC-NeuroCore owns simulators and designs; Loop Timing Witness supplies admitted fabric and timebase interfaces. Spike Log owns container interpretation, Evidence Manifest Toolkit supplies shared evidence operations, and model-profile fitting remains with its owner. Studio renders existing findings.

Self-comparison and planted differences can check the harness; neither supplies measured fabric. A certificate concerns the exact tested simulator, target, network class, configuration and population. It never establishes universal simulator fidelity. Unobservable state is not zero error; absent physical energy measurement remains absent.

## Current tooling

Seven repository controls inspect metadata, source attribution, workflows, dependency alignment, native documentation, inventory and preflight orchestration. Native-tool bootstrap checks selected executable and licence bytes. Domain capabilities, claims and qualified formats remain empty at architecture-only maturity.

Use the exact environment in [Contributing](CONTRIBUTING.md). Named commands are make metadata, make source-provenance, make workflows, make dependencies, make docs, make inventory and make licence. Full CI/preflight belongs in CI or an explicitly admitted pre-push environment. See [Validation](VALIDATION.md).

Read [Architecture](ARCHITECTURE.md), [support](SUPPORT.md), [security reporting](SECURITY.md) and [citation metadata](CITATION.cff). No released comparison package, actual fabric acquisition, numerical guarantee, physical result, DOI or hosted status is claimed.
