# Decision: retain complete paired sources and measurement limits

## Context

Equal network-class labels, repeated simulator traces and an optimal-looking assignment do not prove simulation-to-fabric fidelity. Missing state, clock uncertainty and modeled energy can otherwise hide important differences.

## Decision

Sim Real Witness owns the paired experiment, complete source interpretation, selected greedy matching, metrics and scoped evidence. Simulator/model, fabric instrumentation, container/codec, shared evidence and profile-fitting owners retain their implementations and admission responsibilities. Studio renders existing findings.

## Consequences

Repository controls can be qualified before a paired runner exists. Self-comparison tests the harness only. Actual fabric eligibility needs the full admitted measurement chain and independent current verification. Preserve all original network classes, methods, observations and missing quantities.
