# Repository architecture

## Current executable tooling

Metadata, source-provenance, workflow, dependency-alignment, documentation, inventory and preflight controls inspect declared local scopes. Native bootstrap checks selected executable and licence files. Received metadata cannot choose policy or grant fidelity acceptance. Foundation qualification is in progress.

## Intended comparison boundaries

| Component | Responsibility | Required evidence |
| --- | --- | --- |
| Admission | Complete logical network and inputs for both lanes | Topology, neurons, weights, reset, seeds, numerical semantics, versions and actual consumed inputs |
| Execution | Separate admitted simulation and fabric receipts | Actual adapters, capture, timebase, complete scope and resource limits |
| Interpretation | Complete source containers, state and clocks | Admitted codecs, original indices, gaps, units, epochs and shared uncertainty |
| Matching | Deterministic unused nearest same-neuron assignment | Complete pair journal, signed and absolute deltas, both unmatched populations |
| Analysis | Finite metrics and admitted statistical procedures | Whole neurons, samples, runs, source laws, numerical bounds and optional actual energy |
| Evidence | Full native candidate and separate current verification | Same source, scope, measurement chain and installed independent consumers |

The prospective native format has twenty-one properties, with twenty required and energy_model_error conditional. It retains schema_id, claims, source_ref, environment_ref, simulator, hardware, network, network_class, simulation_input_ref, fabric_input_ref, matching_protocol, measurement_chain, statistics, spike_time_deltas_ref, unmatched_rates, rate_errors, state_errors, state_observability, optional energy_model_error, budget and verdict. This declaration is not registered or qualified support.

Five prospective library operations are execute, match, analyse, report and verify. Original run navigation composes execute then match; certify composes report with required independent current eligibility checks. A candidate report is distinct from an eligible fabric certificate. None of these product commands or aliases is installed.

All three intended classes remain: feedforward LIF, recurrent reservoir and stochastic arithmetic. Bind complete actual network and decoded logical inputs, including quiet neurons, topology, initial state, numerical representation and source versions. Different encodings require an admitted full conversion; unrelated raw hashes or equal class labels cannot establish equivalence. A repeated simulator source is not independent hardware.

Both lanes need actual admitted Spike Log containers and explicit codec interpretation, original ordinals and coverage. Logical spike encoding is a separate declared codec, not image-event relabelling. Model ordinal conventions do not supply physical frequency. Actual state samples differ from recurrence-derived auxiliary state.

Use an earlier affine clock map, common frame and qualified uncertainty. Observation windows are half-open; maximum matching distance is closed. Process simulator events by tick then original index. Choose an unused same-neuron fabric event at minimum absolute mapped distance, breaking ties by fabric time then original index. Keep every source index, signed fabric-minus-simulation delta and both unmatched lists. Never replace this greedy method with global optimal assignment.

Uncertain membership or candidate ordering needs an independently qualified earlier robust rule or an inconclusive result. Gaps, overflow, downtime and uncommitted tails are not silence. Unmatched fractions use separate complete lane denominators; zero denominators are unavailable. Per-neuron signed, absolute and RMSE rates retain real duration and clock uncertainty.

Observable state requires the whole declared captured inventory; partial state lists its actual subset and unobservable state has no fabricated zero errors. Retain variables, units, sampling and prior interpolation rule. Raw state-unit errors differ from a dimensionless normalised auxiliary. Rounded square roots require qualified outward error bounds.

Energy comparison is absent without a complete accepted physical instrument, rail, window, sample, integration and calibration chain. A modelled estimate never supplies measured draw. Relative energy needs a measured denominator with strictly positive conservative lower bound; preserve shared uncertainty.

Six statistical selections remain distinct: complete finite data, independent Bernoulli bounds, independent whole-run distribution bounds, independent Welch equivalence, evidenced paired equivalence and prospective joint-decision power. Each needs its full prior population, law, parameters, stopping, tails and numerical admission. A finite calculation cannot supply an inferential law; event pairs are not automatically independent trials. Joint power concerns the entire decision programme.

No-budget output is descriptive. A prior budget binds exact metric, population, threshold, comparison and simultaneous uncertainty allocation. Within-budget needs every conservative upper to satisfy it; a selected lower violation supports exceeded. Overlap or missing premises stays inconclusive.

Immutable raw bytes precede pair journals, analysis, native candidates, shared manifests, signatures and later receipts. Identical committed retries return original bytes; changed inputs under the same identity refuse. A recapture needs a new identity and cannot silently re-pair an incompatible lane. No signed bytes, private audit or model repeat establishes current physical fidelity. Studio retains the exact tested pair, scope, unavailable state and energy.
