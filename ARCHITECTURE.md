# Architecture

## Current executable surface

Repository validation tooling, dedicated tests, workflow definitions and native documentation are implemented. No lane runner, source adapter, matching engine, statistical backend, report or product command is installed. Domain capability, claim and qualified-format inventories remain empty.

## Intended data flow

A prior complete network, logical input, source, clock, measurement, matching, statistical and budget plan admits both lanes. Actual consumed-input and capture receipts retain separate populations. Complete typed sources feed deterministic matching and full rate/state/optional physical-energy analysis. Native candidates use installed shared evidence operations and separate current verification. Studio renders existing findings.

## Ownership and interpretation

SC-NeuroCore retains simulator/model and DUT implementations. Loop Timing Witness owns actual fabric capture, timebase and instrument admission. Spike Log owns container and codec admission; Evidence Manifest Toolkit owns shared evidence operations. Model-profile fitting, implementation comparison and encoder overlays retain their distinct owners.

Sim Real Witness owns the complete paired experiment and scoped comparison. Equal class labels do not establish identical networks. Matching cannot reuse an event or discard inconvenient observations. Simulation repeats, model-derived state and modelled energy remain distinct from measured fabric.
